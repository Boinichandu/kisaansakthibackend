# 🌾 Kisan Sakthi Backend

Backend service for **Kisan Sakthi**, an intelligent farming assistance application designed to help farmers with crop information, market prices, subsidies, farming tips, weather updates, and expert guidance.

The backend is developed using **Java Spring Boot** and provides REST APIs to connect with the frontend application.

---

## 🚀 Features

### 👤 User Management
- User registration
- User login
- User authentication support
- User profile management

### 📊 Farmer Dashboard
- Display crop-related information
- Show available subsidies
- Display most demanded crops
- Provide farming recommendations

### 🌱 Farming Tips
- Crop-wise farming guidance
- Disease prevention tips
- Cultivation information
- Best practices for farmers

Supported crops:
- Rice
- Maize
- Cotton
- Groundnut
- Chilli
- Tomato
- Onion
- Sugarcane
- Turmeric
- Millets

### 💰 Market Price
- Provides crop market prices
- Helps farmers understand current crop value
- Supports better selling decisions

### 🏛️ Government Subsidies
- Displays available crop subsidies
- Helps farmers find financial support schemes

### 👨‍🌾 Expert Help
- Provides expert information
- Helps farmers connect with agricultural experts

### 🌦 Weather Information
- Provides weather-related information
- Helps farmers plan agricultural activities
